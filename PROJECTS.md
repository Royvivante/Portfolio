# Projects Overview

## ShebaHub (Backend)
ShebaHub is a robust backend solution that provides essential services for mobile and web applications. Designed with scalability and performance in mind, it leverages modern technologies to ensure a seamless user experience. Key features include:
- RESTful API architecture
- Secure user authentication
- Database integration supporting various databases

## TOP ציפויים (E-commerce)
TOP ציפויים is an e-commerce platform tailored for the sale of high-quality coatings and paints. The project focuses on user-friendly navigation, responsive design, and secure payment processing. Key highlights include:
- Comprehensive product catalog
- Advanced search functionality
- Customer review system

## Bitcoin Sentiment Analysis
This project utilizes machine learning to analyze market sentiment regarding Bitcoin by scraping data from social media and news sources. The insights gained help in understanding public perception and potential market movements. Key components include:
- Natural Language Processing (NLP) algorithms
- Data visualization tools
- Timely updates on sentiment trends

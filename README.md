### 📊 Bitcoin Sentiment Analysis — Data Science Research  
**NLP/ML Engineer** | Completed Course Project

An investigation into whether tweet sentiment can predict Bitcoin price direction using classical NLP and deep learning.

**Tech Stack:**
- **Languages:** Python 3.10
- **ML/DL:** TensorFlow, Keras, Scikit-Learn, Pandas
- **Models:** TF-IDF + Logistic Regression, Bidirectional LSTM
- **Data:** ~66,000 Bitcoin-related tweets (temporal split)
- **Statistics:** SciPy (Welch t-test, Bootstrap CI)

**Key Results:**
- Baseline (TF-IDF + LogReg): **ROC-AUC 0.5599**, statistically significant signal at day-level aggregation
- BiLSTM: ROC-AUC 0.5426 (higher recall/F1, but overfitting)
- **Finding:** Linear keyword-based signal outperforms deep sequence models on this dataset
- Day-level aggregation reduces noise; individual tweet predictions unreliable

**Insights:**
- Simple, interpretable models beat complex ones on limited, noisy data
- Temporal data split prevents information leakage
- Sentiment alone is weak; enriched features required for stronger signals

**Repository:** [GitHub](https://github.com/MorSigman/btc_language_signals_project) · **Presentation:** [YouTube](https://youtu.be/0YfxmVveXcw) · **Notebook:** [Google Colab](https://colab.research.google.com/drive/1OkFQIUxDsPFj9k8jPyfHEm9qvcsy5cyS?usp=sharing)
